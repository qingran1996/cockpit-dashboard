# Functional Building Facades Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Differentiate the campus landmark, production, warehouse, process, and utility buildings through function-specific facade massing, loading infrastructure, roof profiles, and service equipment without changing the approved site layout.

**Architecture:** Blender remains the source of truth. New facade and rooftop details are deterministic children of existing `BLDG__*` roots, so Web building selection and floor explosion contracts remain unchanged. Details use existing GLB-safe materials and compact primitive geometry to stay within the 20 MiB asset budget.

**Tech Stack:** Blender 5.2 Python API, glTF 2.0 extras, Node.js `node:test`, React 18, Three.js 0.165, Vite 5.

## Global Constraints

- Preserve all 12 building positions, shell dimensions, `BLDG__*` names, floor nodes, roads, routes, courts, parking, pipe racks, trees, and camera direction.
- Do not use `img2threejs`.
- Keep industrial facade projections within 0.90 Blender units of the existing shell and place major added massing on roofs to preserve access-road clearance. The administration porte-cochere may extend over its existing entrance steps and drop-off forecourt but must not reach a road mesh.
- Use existing materials; do not add external textures or npm dependencies.
- Keep `public/models/factory-campus-graybox.glb` at or below 20,971,520 bytes.
- Regenerate both official `.blend` and `.glb` assets in Blender background mode.
- Keep Blender GUI closed.
- Do not commit or push during this plan because the linked worktree contains earlier uncommitted changes in the same generator, tests, assets, and README.

### Task 2: Build differentiated landmark and industrial envelopes

**Files:**
- Modify: `tools/blender/create_factory_campus_graybox.py`

**Interfaces:**
- Consumes: existing `box`, `cylinder`, `create_administration_facade`, `create_main_production_facade`, and `create_specialized_building_facade` helpers.
- Produces: named facade/roof details under existing building roots; no changes to floor or Web metadata.

- [ ] **Step 1: Enrich the administration landmark**

In `create_administration_facade`, add a shallow porte-cochere roof centered on the entrance at `front_y + 1.55`, four bronze-faced columns, a corporate sign backplate above the atrium, and three-dimensional sign bars. Keep the maximum projection at `front_y + 1.85` and parent every object to `BLDG__administration`.

- [ ] **Step 2: Add high/low production massing**

In `create_main_production_facade`, add `MAIN__roof-monitor` centered above the hall, six clerestory windows on each visible side, and a compact `MAIN__service-annex` against the less-visible side wall. Add two louver banks and a short access canopy to the annex; keep the annex projection within 0.85 units of the shell.

- [ ] **Step 3: Complete the raw-material loading edge**

In the `front-warehouse` branch of `create_specialized_building_facade`, add one continuous `WAREHOUSE__dock-platform`, one `WAREHOUSE__dock-canopy`, four canopy brackets, six safety bollards, and three dock leveler plates aligned with the existing loading doors.

- [ ] **Step 4: Give the finished-goods warehouse its own loading language**

Add an `east-warehouse` branch with `FINISHED__dock-platform`, `FINISHED__dock-canopy`, two framed sectional doors with slats, dock bumpers, high-level vents, and a restrained cyan identity band. Use a two-door rhythm so it is visually distinct from the three-door raw-material warehouse.

- [ ] **Step 5: Expose process and utility functions**

Add an `east-process-hall` branch with a front louver strip, `PROCESS_HALL__pipe-entry-frame`, three short pipe penetrations, and a rooftop scrubber cylinder with cap and access plinth. Add a `far-east-utility` branch with a full-width `POWER__louver-bank`, eight horizontal slats, `POWER__roof-equipment-skid`, two compact rooftop equipment boxes, and two exhaust stacks.

- [ ] **Step 6: Run the contract against a temporary generated fixture**

Generate temporary `.blend/.glb` assets and run the focused contract test with `BLENDER_TEST_BLEND` and `BLENDER_TEST_GLB` pointing to them.

Expected: PASS for all required functional nodes, correct parents, non-zero geometry, and unchanged building shells.
