# 交互式 3D 工业园区变更设计规格

## 目标

将能源综合监控大屏中央的静态工业园区图片替换为完全由 Three.js 实时渲染的可交互 3D 场景。场景延续参考原型的等距构图、青蓝全息建筑和橙色热能设施，并支持鼠标旋转、滚轮缩放、建筑悬停高亮与点击状态详情。

该变更只替换中央园区主视觉。水、电、蒸汽监控面板、顶部标题栏和底部综合指标保持现有结构与数据不变。

## 视觉构图

场景使用悬浮方形工业园区底座：

- 左后区域：三个圆柱储罐、一个球顶水罐和一个高架水塔。
- 中后区域：两座细烟囱、一座高温主烟囱及辅助处理设备。
- 中央区域：两座橙色热能厂房，作为园区视觉焦点。
- 右侧区域：两座青色办公/控制楼和一座大型能源控制中心。
- 地面系统：道路、建筑基座、管线、电路轨迹、发光节点和边缘护栏。
- 环境系统：深蓝空间背景、低密度粒子、网格地平面和轻微雾化。

几何造型以参考图轮廓为依据，不尝试恢复单张图片中不可见的背面细节。场景追求相同的视觉语言和空间关系，不声称是原园区的精确工程模型。

## 材质与灯光

- 建筑主体使用深蓝色低粗糙度材质，保留实体明暗关系。
- 建筑轮廓通过边线几何和加色混合发光层表达，不依赖后期 Bloom 管线。
- 水、电及普通建筑使用青色 `#19d7ff`；热能厂房和高温烟囱使用橙色 `#ff7138`。
- 环境光负责整体可见性，主方向光塑造体积，青色和橙色点光源强调能源分区。
- 地面与底座采用深海军蓝，边缘使用青色半透明护栏和动态能量线。

## 交互

- 鼠标左键拖拽旋转场景。
- 滚轮在限定距离内缩放。
- 俯仰角限制在能保持园区可读的区间，禁止翻转到地面下方。
- 无操作时保留非常缓慢的自动旋转；用户开始交互时立即暂停，短暂空闲后恢复。
- 指针悬停建筑时，建筑轮廓和材质亮度提升，并显示名称标签。
- 点击建筑后在中央区域右上角显示详情卡，包含设备名称、类型、负载或容量、温度与运行状态。
- 点击场景空白处关闭详情卡。
- 建筑状态同时使用中文文字和颜色表达。

## 架构与组件边界

- `IndustrialScene.jsx`：创建 Canvas 容器、管理选中建筑状态、渲染 HTML 标签和详情卡。
- `useIndustrialScene.js`：管理 Three.js renderer、camera、scene、controls、raycaster、动画循环、尺寸观察和资源释放。
- `sceneFactory.js`：创建园区底座、建筑、道路、管线、粒子和灯光，返回场景对象及可交互建筑注册表。
- `buildingFactory.js`：提供厂房、办公楼、水罐、水塔、烟囱和控制中心的程序化建模函数。
- `buildingRegistry.js`：集中保存建筑标识、名称、类型、指标、状态和位置。
- `sceneMath.js`：提供指针坐标归一化、设备像素比限制和可测试的相机约束计算。

Three.js 对象不读取 React 组件状态。Hook 通过回调把悬停和选中建筑标识传回 React，HTML 层根据注册表渲染标签与详情卡。

## 数据流

1. `IndustrialScene` 读取建筑注册表并调用 `useIndustrialScene`。
2. Hook 调用 `sceneFactory` 创建场景与可交互对象。
3. 指针移动时 Raycaster 返回建筑对象，通过 `userData.buildingId` 映射到注册表。
4. React 更新悬停标签或选中详情卡，不重新创建 Three.js 场景。
5. 窗口变化时 ResizeObserver 更新 renderer 尺寸和 camera aspect。
6. 组件卸载时取消动画帧、移除监听器并释放 geometry、material、texture、renderer 和 controls。

## 性能与降级

- 渲染器像素比上限为 `2`，普通设备使用 `min(devicePixelRatio, 2)`。
- 重复能量节点和粒子使用 `InstancedMesh` 或 `Points`。
- 同类建筑共享材质模板，单个交互对象只克隆需要高亮的材质。
- 不引入高成本后期处理和外部模型文件。
- 检测 `prefers-reduced-motion: reduce` 后关闭自动旋转、粒子漂移和能量流动，只保留手动交互。
- WebGL 初始化失败时显示纯 CSS 网格占位与“3D 场景不可用”提示，其他监控区域继续工作。

## 可访问性

- Canvas 提供描述性 `aria-label`。
- 详情卡使用明确标题和状态文字。
- 场景不是获取核心监控数据的唯一途径；左右面板仍提供关键指标。
- 指针标签不阻拦鼠标事件。

## 验证标准

1. 页面不再请求或显示 `industrial-park.png`。
2. Three.js Canvas 能显示至少十个独立工业设施，以及底座、道路、管线和能源节点。
3. 旋转、缩放、悬停、选择和空白取消均可在真实浏览器中操作。
4. 1440 × 900、1920 × 1080、2560 × 1080 下 Canvas 不覆盖数据面板，主体完整且无拉伸。
5. 浏览器控制台无错误，生产构建成功。
6. 场景数学和建筑数据映射测试通过。
7. 卸载组件后不存在持续动画帧或未释放的 renderer DOM。

## 非目标

- 不创建与原型完全相同的工程级三维模型。
- 不加载外部 GLTF、FBX 或商业模型资产。
- 不实现第一人称漫游、建筑内部结构或设备控制操作。
- 不改变现有数据面板信息架构。
