# 能源综合监控可视化平台设计规格

## 目标

在现有 Vite + React 工程中实现一套可运行、可维护、可自适应的能源综合监控大屏。视觉构图以 `disignpng.png` 为唯一基准，在不把整张参考图直接当页面背景的前提下，尽可能还原其工业园区主视觉、青蓝霓虹框架、左右监控面板、橙色蒸汽监控舱和底部指标栏。

## 实现策略

采用混合还原方案：

- 从用户提供的参考图中裁切中央工业园区，作为核心主视觉素材。
- 标题、面板、指标、状态、图表和装饰框架均由 React、CSS 和 ECharts 实现。
- 页面数据统一由本地配置对象提供，便于后续替换成接口数据。
- 不建设后台、登录、数据编辑或三维场景控制功能。

该方案兼顾视觉相似度和维护性。整图铺底方案虽然截图更接近，但会造成文字重影、响应式失真和内容不可更新；完全重绘三维园区则无法在当前范围内达到参考图的素材质量。

## 信息架构

页面使用 1920 × 1080 的逻辑设计画布，包含以下区域：

1. 顶部状态栏：左侧天气，中间平台标题，右侧日期时间。
2. 左侧水资源监控：月度用水量、管网压力、漏损率、分区用水量。
3. 中央主视觉：工业园区裁切图、电路网格、扫描光和能量节点。
4. 中下蒸汽资源监控：蒸汽流量、压力温度、能源转换效率、锅炉状态。
5. 右侧电力资源监控：实时负荷、分时用电量、供电稳定性、变电设备状态。
6. 底部综合指标：总用水量、总用电量、总用汽量、综合能源能耗、碳排放量。

视觉层级上，中央园区是主角；左右面板提供高密度监控信息；橙色蒸汽舱作为唯一的暖色风险区域；底部指标负责快速扫读。

## 组件边界

- `App`：负责画布、整体布局和数据装配。
- `DashboardHeader`：天气、标题和实时时钟。
- `TechPanel`：可复用的青色或橙色切角面板容器。
- `WaterPanel`：水资源指标和柱状图。
- `PowerPanel`：电力指标、曲线图、环形图和设备状态。
- `SteamPanel`：蒸汽曲线、压力温度、效率环和锅炉状态。
- `IndustrialHero`：园区主图、网格、扫描光、节点脉冲和粒子层。
- `BottomMetrics`：五项汇总指标。
- `Chart`：封装 ECharts 初始化、尺寸变化和卸载清理。

组件通过显式属性接收数据，不直接读取彼此内部状态。图表实例只存在于 `Chart` 内部。

## 视觉系统

### 色彩

- 深渊底色 `#020c17`
- 面板底色 `#061b2c`
- 电弧青 `#19d7ff`
- 深能量蓝 `#0878d8`
- 蒸汽橙 `#ff7138`
- 状态绿 `#30e58d`

青色承担平台框架、水和电力信息；橙色仅用于蒸汽舱、热能节点和火焰状态。背景使用低对比电路纹理和蓝色雾化光，不使用通用渐变卡片。

### 字体

- 标题：`Microsoft YaHei`, `PingFang SC`, sans-serif，较宽字距和青色外发光。
- 正文：`PingFang SC`, `Microsoft YaHei`, sans-serif。
- 数字：`DIN Alternate`, `Arial Narrow`, sans-serif，强化数据密度和仪表感。

### 结构语言

面板使用切角、多层描边、角标和细刻度线构成。所有装饰必须表达分区或能量流向，不加入与主题无关的光斑。中央工业园区的“电路能量网络”是页面的记忆点。

## 动态与数据流

- 页面加载时各区域以轻微透明度和位移依次进入。
- 园区扫描光缓慢扫过，能量节点以错峰脉冲显示。
- 图表曲线保持静态数据，但提示框可交互。
- 顶部时钟每秒更新。
- 窗口尺寸变化时统一更新逻辑画布缩放，ECharts 使用 `ResizeObserver` 重绘。
- 检测 `prefers-reduced-motion: reduce` 后关闭非必要动画。

所有演示数据定义在单独的数据文件中。未来接入接口时，只需替换数据提供层，组件结构和图表配置保持不变。

## 自适应规则

- 以 1920 × 1080 为逻辑画布，使用 `min(viewportWidth / 1920, viewportHeight / 1080)` 等比缩放。
- 视口比例不是 16:9 时，主体保持完整且居中，空余区域由背景电路纹理延展。
- 普通笔记本允许整体缩小，不重新折叠面板，避免破坏大屏信息结构。
- 超宽屏不横向拉伸主体，不改变左右面板与中央园区的相对比例。
- 页面不出现核心内容裁切；必要时只裁切最外层背景纹理。

## 容错与可访问性

- 中央素材加载失败时显示纯 CSS 网格与标题占位，不阻塞其他监控区域。
- 图表容器始终提供固定最小高度，避免初始化时尺寸为零。
- 关键状态不只依赖颜色，同时提供“正常”等文字。
- 保留可见焦点样式；提示框和动态装饰不拦截指针事件。

## 验证标准

1. `npm run build` 成功，无 React 或 ECharts 运行时错误。
2. 1920 × 1080 下六大区域的位置、比例和色彩层级与参考图一致。
3. 在 1440 × 900、1920 × 1080、2560 × 1080 三个视口下截图检查：主体完整、文字可读、无溢出或拉伸。
4. 图表在窗口变化后正常重绘，页面卸载时无残留实例。
5. 实时时钟、图表提示框、动画降级和素材失败占位正常工作。

## 非目标

- 不实现真实后端接口和数据持久化。
- 不把中央园区重建为可旋转的 Three.js 模型。
- 不为移动端重排成纵向业务页面；小屏仅保证完整缩放浏览。
- 不复刻参考图中的乱码、重复刻度或明显生成瑕疵，文字使用语义正确的中文。
