# 能源综合监控可视化平台

基于 React、Three.js 与 ECharts 构建的能源驾驶舱大屏。项目将水、电、蒸汽等能源指标与可交互的三维工业园区结合，在同一块 1920 × 1080 可视化画布中展示园区运行状态、能源趋势和设施信息。

## 主要功能

- 水资源、蒸汽资源、电力资源及综合能耗指标展示
- ECharts 柱状图、折线图、仪表状态和分区数据可视化
- 基于 Three.js 代码生成的三维工业园区，无需外部 GLB 模型
- 16 栋可交互建筑，包含生产、仓储、动力、办公、研发和环保设施
- 厂区道路、停车场、双闸门、围栏、绿化、篮球场和管廊系统
- 园区行人及车辆循环动画，车辆可通过闸门驶入内部停车区
- 鼠标悬停显示建筑名称，点击建筑平滑切换至对应近景
- 沉浸式第一人称漫游，支持人物视角行走、摆臂、视角起伏和建筑碰撞
- 根据浏览器窗口自动等比缩放，兼容宽屏和常见笔记本分辨率
- 支持 `prefers-reduced-motion`，并提供 WebGL 不可用时的提示

## 技术栈

| 技术 | 用途 |
| --- | --- |
| React 18 | 页面组件与交互状态 |
| Three.js | 工业园区建模、渲染、拾取与漫游 |
| ECharts 5 | 能源统计图表 |
| Vite 5 | 本地开发与生产构建 |
| Node.js Test Runner | 场景结构、布局及交互逻辑测试 |

## 快速开始

建议使用 Node.js 18 或更高版本。

```bash
git clone https://github.com/qingran1996/cockpit-dashboard.git
cd cockpit-dashboard
npm install
npm run dev
```

开发服务器启动后，按照终端显示的地址在浏览器中打开项目。

## 三维园区操作

### 俯瞰模式

| 操作 | 功能 |
| --- | --- |
| 鼠标拖拽 | 旋转园区视角 |
| 鼠标滚轮 | 缩放园区 |
| 悬停建筑 | 显示建筑名称和类型 |
| 点击建筑 | 切换至建筑近景并显示运行数据 |
| 复位视角 | 返回园区默认俯瞰位置 |

### 第一人称模式

点击场景右下方的“第一人称”按钮进入人物视角。浏览器允许 Pointer Lock 时，鼠标会被锁定并隐藏。

| 操作 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` | 前后左右行走 |
| 方向键 | 前进、后退或左右转向 |
| 移动鼠标 | 调整观察方向 |
| `Shift` | 加速奔跑 |
| `Esc` | 释放鼠标并显示光标，保持第一人称位置 |
| 点击场景 | 再次锁定鼠标进入沉浸操作 |
| 退出漫游 | 返回园区俯瞰模式 |

第一人称移动包含园区边界限制、建筑碰撞和沿墙滑动处理，避免人物穿过围栏或建筑物。若浏览器不支持 Pointer Lock，可使用鼠标左键拖拽转向。

## 项目结构

```text
src/
├── components/                 # 驾驶舱面板和三维场景组件
├── data/                       # 能源监控演示数据与图表配置
├── hooks/                      # 时钟、视口缩放和 Three.js 场景控制
├── scene/
│   ├── factoryCampusRegistry.js # 建筑信息、位置和尺寸注册表
│   ├── factoryCampusFactory.js  # 厂区建筑及场地程序化建模
│   ├── buildingFactory.js       # 建筑立面与屋顶几何生成
│   ├── sceneFactory.js          # 场景装配和运行时交互结构
│   └── sceneMath.js             # 相机、碰撞及第一人称运动算法
├── styles/                     # 大屏、面板和漫游控件样式
└── App.jsx                     # 页面主布局

tests/                          # Node.js 自动测试
```

## 数据和园区配置

- 能源指标及图表数据位于 `src/data/dashboard.js`。
- 建筑名称、类型、指标、坐标和尺寸位于 `src/scene/factoryCampusRegistry.js`。
- 道路、围栏、停车场、车辆路径及园区装饰位于 `src/scene/factoryCampusFactory.js`。
- 相机近景、第一人称出生点、移动速度和碰撞逻辑位于 `src/scene/sceneMath.js` 与 `src/hooks/useIndustrialScene.js`。

修改建筑位置时，建议同时运行 `npm test`。测试会检查建筑重叠、安全间距、道路穿模、停车位、闸门开口和第一人称碰撞等约束。

## 浏览器建议

建议使用最新版 Chrome 或 Edge，以获得完整的 WebGL、Pointer Lock 和硬件加速支持。若页面提示“三维场景不可用”，请确认浏览器已启用 WebGL 和图形硬件加速。

## 模型说明

当前工业园区依据单张效果图进行程序化重建。可见建筑布局、主要道路和标志性设施已按参考图设计；由于单张图片无法提供被遮挡区域和建筑背面的精确尺寸，隐藏区域采用与可见立面一致的工业建筑语言进行合理补全。
